# AI 味校验协议（成稿后）

参考 `larashero3-dotcom/lieflat-less-ai-tone` 公开的两轮实测（629 篇对照 + 270 对同题同事实配对复测）与语义判据。原项目以 CC BY-NC 4.0 发布；本文件只转述可迁移的指标、分级与防误改原则，不复制其代码。数字用于诊断，不是生成配额。

## 0 先决条件：源书基线优先

1. 任何可疑特征先查 `01-style-profile.md` 记的源频率。
2. 源书本来就这么写、且成稿未超源频率 2 倍的，不判 AI 味——通用检测器报警也不改。对偶、分号、破折号、长句、文言虚词、四字格、第一人称论辩都在此列。
3. 只有「源书没有、或成稿明显高于源书」的写法，才进入下面的处置。
4. 冲突顺序：用户指令 > 风格参考 > 剖面规则 > 硬约束 > 通用 AI 味清单。
5. 检测结果只描述文本特征，不反推「这篇文章是 AI 写的」。
6. 没有源书时，用同类文体的人类参考值作基线，并在报告里标注「无源书基线」，不得假装有源书豁免。

## 1 三层检测

### 1.1 脚本可数层

| 项目 | 判据 | 研究参照 | 级别 |
|---|---|---|---|
| 翻案腔 / 对举 | 「不是 A 而是 B」「并非 A 而是 B」「与其说……不如说……」「表面……实际……」「看似……实则……」「你以为……其实……」「A 不重要，重要的是 B」 | AI 0.73 / 人类 0.22 每千字（3.4 倍）；配对复测 δ +0.88 / +0.72，最强纯写作信号 | A/B |
| 结论提示冒号 | 冒号前是「核心是」「关键在于」「原因如下」「一句话总结」「残酷的现实是」这类结论宣告，冒号后展开 | AI 2.1 倍于人类 | A |
| 起手式 | 「说白了」「说穿了」「先说结论」；作结论前缀的「说到底」同类 | 3.2 倍 | A |
| 前置长定语 | 中心名词前修饰超过 15 字，或一句里两个以上「的」叠加 | δ +0.48 / +0.54 | B |
| 「当……时」前置从句 | 句首「当……时，……」可改成前一分句 | 翻译腔四型之一 | B |
| 话题壳 | 「对于……来说」「就……而言」「在……方面」后面的句子本来就以该对象为主语 | 翻译腔四型之一 | B |
| 句首连接词路标 | 连续段落以「然而」「因此」「此外」开头 | 翻译腔四型之一 | B |
| 密集并列 | 一个分句内两个以上顿号、连起三项以上；或连续分号串三档 | 密集并列 AI 1.45 倍；顿号 δ +0.56、分号 δ +0.80（GPT） | B |
| 相邻句同构 | 连续三句主语、谓语、宾语位置基本一一对应，只换填入的词 | 高度同构 AI 29.4% / 人类 10.7% | B |
| 句长均匀 | 句长 CV 明显低于同类文体 | AI 0.41–0.55，人类 0.54–0.67（轮次不同，不混算） | C |
| 结构碎 | 小标题密度高，节长短且方差小 | AI 中位 7 节 / 人类 1；1.3–1.7 个标题每千字 | C |
| 段段紧扣 | 连续「明确承接」接口 ≥6 个 | AI 中位 7 连环 / 人类 2；明确承接 98.9% / 95.2% | B/C |
| 同义重命名 | 同一实体或概念在段内换两种以上实义说法 | AI 0.83–0.86 次每段 / 人类 0.49；重灾段 20.6–22.5% / 8.4% | B |
| 破折号 / 分号 / 引号 | 密度与方向 | 破折号 >2 每千字为优先线；分模型分化，不能反推模型 | F |
| 问句密度 / 长短句配比 | 问句多少、长句与短句占比 | 单模型指纹，不是通用规则 | F |

整篇分布指标只报实测值，不伪造逐句命中；不同轮次口径不可混算倍数。

### 1.2 语义判读层（封闭标签）

只判候选，不凭整体感觉。每条给标签、置信度（高/中/低）和一句话理由；拿不准用兜底标签。

1. **同义重命名**（段级）：同一实体或概念在段内换实义说法。标签：0 组 / 1 组 / 2 组 / 3 组以上 / 无法判断。≥2 组为处理对象；改法是把同义链统一回原名词。
2. **衔接方式**（段间接口）：标签：表面有连接词实际关系不清 / 明确承接 / 有关但转换突然 / 主题跳转缺少说明 / 无法判断。连续「明确承接」≥6 个接口算连环；改法是在连环中留 1—2 处自然跳跃，优先处理「连接词不成立」的接口。
3. **冒号分类**：标签：引语或人物发言 / 标题时间比例元数据 / 定义或解释 / 空转提示 / 结论提示 / 其他正文冒号 / 无法判断。只改「结论提示」。
4. **高度同构三连**：标签：高度同构 / 部分同构 / 只有词语重复句法不同 / 只有语义并列句法不同 / 无同构关系 / 无法判断。≥2 组高度同构为处理对象；改法是拆掉其中一句的骨架，不删内容。

### 1.3 人审层

- 比喻贴不贴切、暗喻与拟人喻体是否硬套、三个并列案例是否凑数、参差是否有质量：模型只列原句，不评级、不给改法。
- 默认保留比喻；用户明确要求时才逐条处理。

## 2 分级与处置

| 级 | 含义 | 处置 |
|---|---|---|
| A 机械改 | 固定句式、提示语、标点，改动不碰语义 | 复核误报后列为拟改 |
| B 建议改 | 需句式重组、换说法、合并同类项 | 逐条筛选，给例句与改法 |
| C 只报告 | 句长、节长、结构等整篇分布 | 默认不改；用户要求时再处理 |
| F 指纹 | 破折号、分号、引号、问句等分模型偏好 | 只报方向；可定位且能安全改的局部命中可列拟改 |
| X 已否决 | 实测不是 AI 味 | 永不改，报告里保留计数防误改 |
| H 人审 | 比喻、拟人、案例凑数、参差质量 | 只列不改 |

**X 级清单**：序数词小标题；「这意味着」「这表明」式复述；空转句引列表（「我见过的几种场景：」加列表）；概括替代（同段有数据也不改）；段首零回指；低密度破折号补写；给学术、新闻、公文硬加「我」「你」。

**报告格式**：

| 级别 | 项目 | 本篇命中 | 源书基线 | 人类参考 | 处置 |
|---|---|---|---|---|---|

每项附 1—2 处可定位原句、命中机制和可执行改法。报告发出后等用户确认，再进入改写；用户回复「按建议改」即按拟改清单执行，不再二次确认。

## 3 改写原则

1. **最小改动**：一处命中只改必需部分，不顺便润色、不换没问题的词。
2. **信息守恒**：观点、事实、限定词、数字、日期、引语、因果完整保留；改写后每个实词都能在原文指出出处。
3. **不制造参差**：不为「像人写」把句子改得忽长忽短、把段落拆碎；句长 CV 不是目标值。
4. **结构不动**：标题层级、章节顺序、段落顺序、列表、表格、引用、代码块原样保留。
5. **风格参考优先**：有文风 Skill 时以 `01-style-profile.md` 为准；作者本来就爱用的破折号、分号、对偶，不按通用指纹删。
6. **引文与清单不改**：人物原话、参考文献、代码块、配置清单、法规条目保持原样。
7. **改后复测**：重算同一组指标，核对拟改项是否完成、误报是否有说明、C 级指标是否没有大幅摆动；每处改动能指出对应规则，指不出就撤销。

## 4 不改的情况

- 对话体、口语体：本来就是自然表达。
- 正文问句、设问、问句小标题：人类用得比 AI 多，删了更不像人写。
- 文学性表达：散文、小说的排比与比喻按原有风格判断。
- 体裁要求：学术、新闻、公文不必强加「我」「你」。
- 代码块、外语段落、引文。
- X 级清单全部不改。

## 5 验收

- [ ] 每项可疑特征都先对过源书基线；源书 2 倍以内未误改
- [ ] A/B/F 拟改项有原句、改法、理由；保留项有具体理由
- [ ] X 级零改动；H 级只列不改
- [ ] 改写后信息守恒：数字、专名、限定词、引语无丢失
- [ ] 已复测，C 级指标未大幅摆动
