# 写作指导：pha风格（基于《人生拒绝清单》）

## 适用场景

本指导适用于需要模仿pha写作风格的创作任务，包括但不限于：续写、仿写、风格化改写、风格校验。指导基于单本《人生拒绝清单》（【日】pha 著，程俐 译，湖南文艺出版社2025年2月版）提取，覆盖该书的写作特征，未涵盖作者其他作品的风格变化。本书为译本，语言层面的规则含译者程俐的风格影响，需审慎采用。

## 一、风格总纲

1. **以"废柴"自居的示弱姿态入场**：用自贬标签（废柴、懒惰、浑身没劲）放低言说者位置，以示弱换取松弛感，绝不以导师口吻说理。
2. **以"否定"为方法论搭建结构**：每个论点以"不做/不拥有/不期待"的否定式切入，以悖论句式（懒惰是美德、降低期待更轻松）驱动说理。
3. **极短段落呼吸式节奏**：每个自然段仅含1-2句话，大量单句成段，以高频换行制造松弛可读的节奏。
4. **私人经验 + 流行文化 + 学术概念的三重引用**：每篇以"我"的具体处境起头，穿插漫画情节与社会学/心理学理论，形成"宅文化知识分子"的引用谱系。
5. **丧中带暖、说理不逼人**：悲观底色上覆盖务实善意，论点末尾以"让我们……吧"祈使句松散收束，常自我修正留有余地。

|:---:|---|---|---|---|

| 2 | `02-structure-layout.md` | 写作框架与谋篇布局 | 规划否定式总分总结构、清单体单元、跨章回指网络 | 依赖维度1确立的调性与立场 |

### 执行方式

- **完整写作任务**：按顺序1→8依次加载每个文件中的规则，逐步落实。**内容按规则全新生成**：「种子文本库」（见第五节）仅作结构参照与语感校准——选取结构最接近的种子文本，使新段落对齐其段落功能、句长节奏与收束方式；禁止改写原文句子、禁止套用原文句式骨架。
- **局部改写/校验任务**：可直接加载对应维度的文件单独执行。改写后仍须执行种子文本语感校准。
- **风格校验任务**：先执行维度1确立基调，再跳至维度8做认知终检，最后用下方校验清单逐条核对。
- **🤖 AI特征校验**：写作完成后，须逐维度检查🤖 AI特征规避规则，确保不触发AI典型写法。

## 三、风格校验清单

写作完成后，逐条校验文本是否符合各维度规则：

- [ ] 文风基调是否符合「风格总纲」的核心原则

- [ ] 维度2：谋篇布局是否遵循 `02-structure-layout.md` 的硬性规则
- [ ] 维度3：主题与素材选择是否遵循 `03-theme-material.md` 的硬性规则
- [ ] 维度4：节奏与信息密度是否遵循 `04-rhythm-density.md` 的硬性规则
- [ ] 维度5：行文逻辑是否遵循 `05-logic-texture.md` 的硬性规则
- [ ] 维度6：句式与用词是否遵循 `06-word-sentence.md` 的硬性规则
- [ ] 维度7：修辞选择是否遵循 `07-rhetoric.md` 的硬性规则
- [ ] 维度8：认知模式与价值立场是否遵循 `08-cognition-value.md` 的硬性规则
- [ ] 是否触犯任一维度的「避免」规则
- [ ] **是否触犯任一维度的🤖 AI特征规避规则**
- [ ] 段落粒度是否存在跳跃（非全程均匀段落）

- [ ] 段间过渡是否存在不平滑的跳跃（而非全程平滑衔接）
- [ ] 用词是否保持粗糙感（非精致书面词汇）
- [ ] （译本来源）是否误用了含译者风格影响的语言规则

## 四、边界说明

本指导基于《人生拒绝清单》单本书提取，pha在其他作品（如《尼特族的生存之道》《未拥有的幸福论》）中的风格可能有变化。本书为译本（程俐译），语言层面的规则（维度6词句习惯、维度7修辞技法）含译者风格影响，需审慎采用；叙事结构、谋篇布局、主题取向、认知模式等层面受译者影响较小，可较为放心地参照。

## 五、种子文本库（全局强制）

> **用法**：种子文本是原文的结构范式与语感基准，仅作段落功能、句长节奏、过渡与收束方式的参照；写作内容一律按规则全新生成，禁止改写原文。以下为从《人生拒绝清单》中摘录的种子文本，每段标注出处与功能类型。

### 种子1：开篇段（自贬入场 + 论点前置）

> 我从小就懒，动不动就喊累，既不擅长交际，也不善于结交朋友，每天去学校都很辛苦，就想一直在家睡大觉。
> ——前言

**结构特征**：第一人称自贬开场 → 列举具体弱点（懒、累、不擅交际） → 以日常场景（学校/睡大觉）收束。句长递增，最后一句最长。

**生成示范**（以"拖延症"为主题）：
> 我从小就磨蹭，干什么都慢半拍，既不擅长规划，也不善于管理时间，每天起床都很挣扎，就想一直赖在被窝里不动。

### 种子2：论证段（归纳推理 + 因果链条）

> 我在公司上班的时候，就曾经陷入这样一个毫无道理的怪圈中。工作太忙，没有自己的时间，于是花钱买便利和服务来节省时间。但为了支付这些便利和服务的费用，又不得不更加努力地工作。结果时间越来越少，只能花更多的钱来购买便利。
> ——不用钱来解决

**结构特征**：白描个人处境 → 因果链条（忙→买服务→付钱→更忙→花更多钱） → 恶性循环收束。句子长度均匀，靠因果词衔接。

**生成示范**（以"知识焦虑"为主题）：
> 我前阵子也陷进过这种怪圈。觉得知道得太少，于是买课程、订专栏、囤书单。但为了消化这些内容，又不得不挤压实际做事的时间。结果事没做成多少，焦虑倒更深了。

### 种子3：引用段（个人独白 + 行为白描）

> 说到我自己，每隔几年，我都会冲动地想："哇，我完了，我已经厌倦了一切，我过不下去了，我想抛开一切，做点别的事！"每每如此，我都会辞职或者搬家。
> ——不积累

**结构特征**：口语化独白引述 → 感叹号密集的情绪宣泄 → 白描行为（辞职/搬家）收束。句子长度跳跃大。

**生成示范**（以"社交退缩"为主题）：
> 说到我自己，每隔几个月，我都会冒出一个念头："算了，我受够了，我不想再应付任何人了，我想把手机关了，谁也别找我！"每每如此，我就会消失几天，谁的消息都不回。

### 种子4：辩证让步段（自我修正 + 松散收束）

> 当然，人生并不都是心想事成的，在某些情况下，你不得不做一些令你痛苦或你不喜欢的事。即便如此，如果可能的话，最好还是尽量避免做自己讨厌的事。
> ——不做自己讨厌的事

**结构特征**：让步（"当然"） → 承认例外 → 折中立场收束。两句构成完整论证，松散收束。

**生成示范**（以"完美主义"为主题）：
> 当然，追求精细本身没什么错，有些事情确实需要反复打磨。即便如此，如果每件事都死磕到底，最后可能什么也做不成。

### 种子5：祈使收束段（风格锚点）

> 让我们珍惜睡眠，好好生活。
> ——不削减睡眠时间

**结构特征**：极短单句 → "让我们……"祈使格式 → 松散收束，无总结升华。

**生成示范**（以"放下执念"为主题）：
> 让我们放过自己，慢慢来吧。

## 六、种子文本结构参照流程（全局强制）

> 写作时必须按以下流程执行，禁止跳过任何步骤；内容一律全新生成，种子仅作结构参照。

### 步骤1：种子选取

根据写作主题，从种子文本库中选取1-2段结构最接近的种子文本：
- 开篇段 → 选取种子1
- 论证/分析段 → 选取种子2
- 个人经验/引用段 → 选取种子3
- 辩证/让步段 → 选取种子4
- 收束段 → 选取种子5

### 步骤2：结构映射

分析种子文本的以下结构特征，作为新段落的对齐参数：
- 段落功能（开场/论证/让步/收束）
- 句长节奏（新段落各句的字数区间与种子文本的分布保持一致，允许±5字浮动）
- 段落粒度（单句成段还是多句段落，与种子文本一致）
- 过渡方式（因果词衔接、语义跳跃、设问转折，与种子文本一致）
- 语气助词位置（"吧""呢""嘛"等助词在新段落中的位置参照种子文本的分布）

### 步骤3：按规则生成

按八维度规则生成全新内容，禁止逐句改写原文：
- 内容、主题、例证须完全原创，不得出现原文的人物、语句与论点表述
- 句式类型参照种子文本的功能（如自贬开场、定义式短句、祈使收束），但不套用原句的语法框架做词语填充
- 保留pha的语气助词、标点习惯、感叹号位置等语言惯性（来自维度6规则，非来自某一段种子）

### 步骤4：语感校准

成稿后与种子文本对照校验：
- [ ] 段落功能是否与目标段落一致（开场/论证/让步/收束）
- [ ] 句长节奏是否与种子文本的分布一致（允许±5字浮动）
- [ ] 段落粒度是否与种子文本一致（单句成段/多句段落）
- [ ] 过渡方式是否与种子文本一致
- [ ] 语气与语感是否接近原文（克制、自嘲、示弱）
- [ ] 内容是否完全原创（无原文句子改写、无句式骨架填充痕迹）
