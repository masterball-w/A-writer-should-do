# 语言剖面（《蛙》）

统计基线：全书 7308 句；均值 25 字，中位 21 字；≤10 字 19.8%，≥41 字 14.8%；问号 14.0%，感叹号 13.5%；冒号 1382 处，引号 0 处；单句段 22.8%；最长 420 字，最短 2 字。以下数字只描述原作，用于诊断，不是写作配额。

## 一、语音与韵律

- 音节搭配偏口语：单音节动词、量词承担动作，双音节名物承担列举。
- 叠词、拟声、顺口溜用于口语场面与人物说唱；出现时整段引入，不拆成书面描述。
- 四字格连缀（醍醐灌顶、火冒三丈、哭天抢地、手足无措、生龙活虎、沧海桑田、优哉游哉）落在叙述者的转折与收束处，与土语形成音节落差。
- 句末多落在动作、名物或判断上，少落在形容词上；长句收尾常是一个短促的谓语或名词短语。
- 朗读检查：一口气读不完的长句应来自名物列举或口语倾诉，不能靠从句套从句。

## 二、词法与语域

- 词性：动作动词与具体名词密度高；抽象形容词、情绪形容词少。
- 称谓与专名原样重复：原书「姑姑」1194 次、「陈鼻」244 次、「王胆」113 次；不用「她」「这位老人」回指。
- 人物专用（乡土口语+粗口）：腚、嫚、拉呱、耍死狗、杂种、老妖婆子、屁颠屁颠、麻了爪子、臭娘们儿、熊孩子、打溜儿、忽悠。
- 叙述者专用：四字格连缀；文言词与书面成句式（如八字对偶）用于抬调与收束，宁少勿多。
- 高频虚词与插入语：当然（76）、仿佛（66）、后来（60）、似乎（44）；「先生」作段首称谓 95 处。它们承担插话、让步、半信半疑的转述，不按次数硬塞。
- 语域并置：同段允许四字格与土话粗口共存，但各归其位：人物说土语，叙述者说文词。
- 时代词、政策词、公社用语是词汇材料，只在对应年代题材使用。

## 三、句法

- 流水句：一个主语带多个谓语，分句用逗号串接，靠语序和语义推进；转折、判断处才断句。
- 名物列举：用「有的……有的……」「什么A、B、C」把名物、动作、数字连续铺开，允许句子失控延长。
- 短句定性：`名词短语+逗号+主语+动作。` 删除修饰，只留判定；用于转折、应答、收束。
- 转述句：`人名+说：` 是默认叙事引擎；转述与现场交替，动作可插在话中间。
- 对话零引号：`人名+动作/神态+说/道/问/骂道：内容`；话与叙述同段混排，可整段不分行。
- 主谓省略与零形回指：同一话题连续推进时省主语，靠语序识别；换话题时重新出现名词。
- 话题-评论：话题先出，评论随后；评论多为动作或判断，少作解释。
- 关联词常省：因果、转折多靠语义承接，少用「因为/所以/虽然/但是」。
- 连动与兼语：动作连续时用连动式，不拆成多个主谓句。
- 惯用句式：定义式反问（先问「什么X？」再给贬义定性）、双分支推测（「大约是……抑或是……」）、四字四句对偶收束。

## 四、篇章衔接

- 话题链以名词重复维持，少用代词；段落内主语可连续省略。
- 段落硬切：长段展览之后直接切单句或换场面，不写过渡句。
- 意合：分句之间靠语义和语序衔接，少用「于是、因此、然而」等显性连接。
- 引话用冒号接入叙述流，不打引号、不另起行；对话与动作、心理在同一段内交替。
- 结尾停在动作、名词句或问句上，不作总结性议论。

## 五、标点语法

- 冒号：引话入口；原书 1382 处，是对话的主要语法标记。
- 引号：0 处；新作对话同样不用引号（引用他人原话除外）。
- 省略号：用于哀告、语塞、话没说完；破折号用于话头被打断或插入。
- 问号、感叹号：口语场面密集，叙述段稀疏；原书占比只作诊断。
- 逗号承担流水句的分句，句号落在语义完结处，不按长度断句。

## 六、叙述话语

| 项目 | 语言特征 |
|---|---|
| 人称与视点 | 第一人称「我」；叙述者在事件内、回忆之后 |
| 话语呈现 | 转述与冒号引语交替；无引号连续对白 |
| 叙述者标记 | 插话、自嘲、跑题、拉回，用插入语与语气词完成 |
| 情绪手段 | 少用情绪形容词；情绪落到动作动词、短句、标点 |
| 反讽手段 | 庄词谐用、语域落差：四字格或官腔词与土语粗口同句并置，叙述者不评论 |
| 比喻 | 喻体限乡土物件、身体、动物；标志词「仿佛/像/好像/犹如/如同/似的」混用；允许双喻叠加与失配 |
| 省略与跳脱 | 省主语、省连接词、段落硬切；结论不补解释 |
| 开头与收尾 | 开头常用称谓或名物陈述，收尾停在动作、名词句或问句 |

## 七、语感与呼吸点

- 长句的加速度来自名物列举与口语倾诉，不是形容词堆叠；句末用短判断或动作刹住。
- 对话不换行，冒号推进；动作插在话中间，不另起舞台提示。
- 转折处直接断句或换段，不靠过渡词换气。
- 土语与四字格相邻时，音节要能读出落差；读不出就删一方，不折中。
- 朗读检查：拗口处删从句或拆句，不为保留长度硬撑。
