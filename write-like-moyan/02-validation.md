# 语言校验

初稿完成后加载。命中任一条，按「修正」返工。本文件只校验语言，不要求任何故事内容。

## 一、通用 AI 黑名单（12 条）

| 编号 | 禁止项 | 修正 |
|---|---|---|
| A1 | 三段式排比（A在…；B在…；C在…） | 只留一个具体场景或一句概括 |
| A2 | 「不是A而是B」对比推进 | 改直接陈述或具体经验 |
| A3 | 设问自答（为什么…？因为…） | 改直接陈述或场面 |
| A4 | 工整对仗式总结 | 改口语化直白表达 |
| A5 | 每段都用「当然/不过/说到底」过渡 | 多让段落直接跳跃，不逐段加过渡词 |
| A6 | 拟人化修辞（胃抗议、时间流逝） | 改直接身体感受 |
| A7 | 伪亲切「你」（你是否也…） | 改第一人称经验 |
| A8 | 「不+形容词」定义（不简单、不容易） | 改具体描述与数字 |
| A9 | 强制因果（正是因为…所以…） | 删连接词，靠语义承接 |
| A10 | 精致书面词（毋庸置疑、综上所述、信誓旦旦） | 改日常口语 |
| A11 | 精致形容词堆砌（深刻的、本质的、核心的连用） | 每篇不超过 2 个 |
| A12 | 均匀段落、均匀信息密度 | 单句段与长段、极高与极低密度交错 |

## 二、莫言文风专项（5 条）

| 错误 | 修正 |
|---|---|
| 用引号写对话，每句独立成段 | 改「人名+动作+说：内容」冒号流，与叙述混排 |
| 句长匀速，长句靠形容词撑 | 用流水句和名物列举推长，转折、判断处收短；不按字数切 |
| 情绪形容词命名（无尽的悲伤、深深的愧疚） | 删情绪词，改动作动词、短句或标点 |
| 用「她」「这位老人」替换「姑姑」 | 人名原样重复 |
| 语域越界：人物说书面语，或叙述者说土话粗口 | 按说话人分界：人物用土语，叙述者用文词 |

## 三、不复制检查

- [ ] 新作无原文句子、原文人物、地名、情节
- [ ] 未套用原文句式骨架填词
- [ ] 独创比喻未迁移
- [ ] 作者真实经历未搬入

## 四、验收清单

- [ ] 对话全部为无引号冒号形式，与叙述混排
- [ ] 人名与称谓原样重复，无代词回避
- [ ] 语域分界清楚：人物土语、叙述者文词
- [ ] 列举、铺陈用流水句；转折、判断用短句
- [ ] 长句由名物、动作、口语推进，不靠形容词拉长
- [ ] 情绪少用形容词，落到动作动词、短句或标点
- [ ] 反讽靠语域落差或事实并置，不靠叙述者评论
- [ ] 比喻喻体来自乡土、身体或动物，从语言现场生发
- [ ] 开头、结尾为句法型（名词句、动作句、问句），不作总结
- [ ] 冒号引话；省略号、破折号按语气使用；对话不用引号
- [ ] 关联词少用，分句靠意合衔接
- [ ] 未命中通用 AI 黑名单 12 条
- [ ] 换题材测试：把场景换成与原著无关的题材，全部规则仍成立
- [ ] 朗读换气自然；删去「仿佛/当然」等标志词后语感仍在
- [ ] 未复制原句、人物、地名、情节、独创比喻
