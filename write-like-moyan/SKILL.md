# 写作指导：莫言后期文风（基于《蛙》）

## 适用场景

仅覆盖《蛙》的语言层面：第一人称讲述语态、转述句、无引号冒号对话、流水句与名物列举、方言土语与四字格文言的语域并置、标点与篇章衔接。不包含情节、人物、母题、结构等故事层要求，任何题材都可套用。

## 语感总述

读《蛙》像听一个亲历者当面讲话：一句话常挂着几个小分句往前赶，靠名物、动作、称谓越铺越长，到判断处忽然收成短句；对话不换行，顺着冒号继续；土话、粗口、四字格和文言词在同一段里相撞。节奏由嘴上的话推着走，不为漂亮而停顿。

## 文风总纲

1. **讲述语态**：叙述者以「我」在场，事件常经「某某说」转述，插话、跑题、自嘲都用插入语完成。
2. **流水句推进**：分句用逗号连续铺开，一个主语带出多个动作或名物；转折处才断句。
3. **名物密度**：具体名词、量词、称谓、动作动词密集；抽象形容词少。
4. **语域并置**：方言土语、粗口、四字格、文言词同段共存，靠语域落差产生力度。
5. **对话零引号**：冒号引导话语，话与叙述混排，不换行、不分条。

## 硬约束（初稿前加载）

1. **零引号对话**：`人名+动作/神态（可选）+说/道/问/骂道：内容`，话与叙述同段混排，禁止每句对话独立成段。
2. **句长随内容走**：列举、铺陈、口语倾诉时用流水句自然拖长；转折、定性、应答时压短。不按字数切，不凑极差。
3. **人名原样重复**：人名与称谓直接重复，禁止用「她」「这位老人」式替换。
4. **语域分界**：乡土口语与粗口只出自人物之口；四字格与文言词只用于叙述者。
5. **情绪落到语言**：少用情绪形容词；情绪由动作动词、短句和标点承担。

规则不要求出现任何特定事件、人物或主题。

## 最高频失败

1. **引号对话、每句独立成段**：→ 改冒号流，与叙述混排。
2. **句长匀速、长句靠形容词撑**：→ 改流水句，用名物与动作把句子推开，转折处收短。
3. **用代词替换人名**：→ 原样重复。
4. **语域越界**：人物说书面语，或叙述者说土话粗口。→ 按说话人分界。
5. **情绪形容词命名**：→ 改动作动词、短句或标点。

## 加载顺序

1. 动笔前：本文件。
2. 写作中：`01-style-profile.md`，按当前段落功能取词法、句法、篇章剖面与呼吸点。
3. 成稿后：`02-validation.md`。

## 写作流程

1. 定文体、篇幅、叙述位置（默认第一人称、事后讲述）。
2. 先读「语感总述」，再取当前段落功能的词法、句法、篇章规则与呼吸点。
3. 起草；按规则调语域、句法、对话形态、标点，不按指标凑。
4. 成稿后朗读，删去「仿佛/当然」等标志词复读，再执行 `02-validation.md`；成稿保存为 `{标题}.md`。

## 边界

- 单书边界：仅代表《蛙》的语言特征，不代表莫言其他作品。
- 时代词、政策词、公社用语只在对应年代题材使用；它们属于词汇材料，不是文风要求。
- 高密东北乡地名、人名、事件不得进入新作，替换为自设空间。
