# 写作指导：余华小说风格（基于《活着》）

## 适用场景

本指导适用于需要模仿余华小说写作风格的创作任务，包括但不限于：小说续写、仿写、风格化改写、风格校验。指导基于单本《活着》提取，覆盖该书的长篇小说写作特征，未涵盖余华其他作品（《许三观卖血记》《兄弟》《文城》等）的风格变化。与基于散文集《我们生活在巨大的差距里》的 write-like-yuhua（散文版）并存：小说创作任务一律使用本 Skill。

## 一、风格总纲

1. 冷峻克制：死亡与苦难用平静陈述完成，禁止呼天抢地、禁止议论抒情，情绪全部外化为动作与景物。
2. 民间言说：叙述者必须是当事人（第一人称回忆体或框架叙事中的讲述者），语气自嘲、认命、带笑，把最惨的事讲得像家常。
3. 白描为骨：人物、场景、死亡一律素笔勾画，比喻稀少且必须取材乡间日常（盐、柴禾、灯笼、蚊子、泥路）。
4. 凄谐并置：最惨烈的段落旁边允许挂着粗俗的民间幽默，情绪在凄与谐之间突转，不做过渡。
5. 拒绝升华：苦难不产生教训，结尾落在日常动作或田野空镜头上，禁止哲理总结。

## 二、执行顺序与文件索引

写作时须按以下顺序依次加载并执行各维度指导文件。该顺序遵循「先定调→再搭架→定内容→控节奏→理逻辑→炼词句→施修辞→验认知」的递进逻辑，前序维度的决策构成后续维度的约束前提：

| 执行顺序 | 文件 | 维度 | 职责 | 依赖前提 |
|:---:|---|---|---|---|
| 1 | `01-style-personality.md` | 整体写作风格与人格底色 | 确立冷峻克制基调、民间第一人称立场、凄谐情绪底色 | 无（最先执行，为全文定调） |
| 2 | `02-structure-layout.md` | 写作框架与谋篇布局 | 规划框架叙事/死亡链结构、首尾锚点、详略排布 | 依赖维度1确立的调性与立场 |
| 3 | `03-theme-material.md` | 主题取向与内容选择偏好 | 确定忍受母题、底层素材、历史侧写原则 | 依赖维度2确定的结构框架 |
| 4 | `04-rhythm-density.md` | 叙事/论证节奏与信息密度 | 控制段落粒度、死亡密度倒挂、时间硬切 | 依赖维度3确定的内容体量 |
| 5 | `05-logic-texture.md` | 行文逻辑与内容肌理 | 搭建民间因果、行为先于心理、对话推进 | 依赖维度4确定的节奏框架 |
| 6 | `06-word-sentence.md` | 词句习惯与语言惯性 | 约束农民口语词汇、短句连缀、内心独白句式 | 依赖维度5确定的逻辑走向 |
| 7 | `07-rhetoric.md` | 修辞策略与表达技法 | 选择白描、民间比喻、歌谣意象、黑色幽默 | 依赖维度6确定的词句基础 |
| 8 | `08-cognition-value.md` | 认知模式与价值底色 | 校验生存哲学、不控诉立场、拒绝升华 | 最后执行，对全文认知一致性做终检 |

### 执行方式

- **产出落盘**：写作产出须按母 Skill「步骤8：写作产出落盘」执行，成稿以 `{文章标题}.md` 保存到当前工作目录，禁止仅在对话中输出不落盘。
- **禁止从零生成**：写作时必须先从「种子文本库」选取结构最接近的种子段落为模板改写，内容替换比例≤50%，至少半数句式骨架来自种子文本。
- **完整写作任务**：按顺序1→8依次加载每个文件中的规则，逐步落实。初稿完成后，**必须执行「去AI化后处理」**（逐条校验黑名单 + 统计性校验），否则视为未完成。
- **局部改写/校验任务**：可直接加载对应维度的文件单独执行。改写后仍须执行统计性校验。
- **风格校验任务**：先执行维度1确立基调，再跳至维度8做认知终检，然后用下方校验清单逐条核对，最后执行统计性校验。
- **🤖 AI特征校验**：写作完成后，须逐维度检查🤖 AI特征规避规则，确保不触发AI典型写法。此项为去AI化后处理的前置步骤。
- **叙事逻辑自检**：写作产出初稿完成后，须额外执行一遍独立于风格校验的叙事逻辑自检：①人物称谓与排行辈分是否一致；②对话内部是否自相矛盾（如前句问价、后句质疑收钱）；③机构名称、证件有效期、办事程序等设定是否前后一致；④时间、年龄、金额是否自洽。风格蒸馏只提取文风的统计特征，不覆盖叙事逻辑一致性，故此项为独立强制步骤。

## 三、风格校验清单

写作完成后，逐条校验文本是否符合各维度规则：

- [ ] 文风基调是否符合「风格总纲」的核心原则（冷峻克制、民间言说、白描、凄谐并置、拒绝升华）
- [ ] 维度1：叙事立场与情绪底色是否遵循 `01-style-personality.md` 的硬性规则
- [ ] 维度2：谋篇布局是否遵循 `02-structure-layout.md` 的硬性规则
- [ ] 维度3：主题与素材选择是否遵循 `03-theme-material.md` 的硬性规则
- [ ] 维度4：节奏与信息密度是否遵循 `04-rhythm-density.md` 的硬性规则
- [ ] 维度5：行文逻辑是否遵循 `05-logic-texture.md` 的硬性规则
- [ ] 维度6：句式与用词是否遵循 `06-word-sentence.md` 的硬性规则
- [ ] 维度7：修辞选择是否遵循 `07-rhetoric.md` 的硬性规则
- [ ] 维度8：认知模式与价值立场是否遵循 `08-cognition-value.md` 的硬性规则
- [ ] 是否触犯任一维度的「避免」规则
- [ ] **是否触犯任一维度的🤖 AI特征规避规则**
- [ ] 段落粒度是否存在跳跃（单句成段/对话独立成段与长段交错，非全程均匀段落）
- [ ] 是否存在三段式排比或工整对仗式总结
- [ ] 场景切换是否存在时间硬切（而非全程平滑衔接）
- [ ] 用词是否保持民间粗糙感（非精致书面词汇）
- [ ] 死亡/苦难段落是否保持平静陈述（无煽情、无升华）
- [ ] 叙事逻辑自检是否通过：称谓辈分、对话因果、设定一致性、时间数字均无矛盾

## 四、边界说明

本指导基于《活着》单本书提取，余华在其他作品中的风格可能有变化（先锋期短篇更实验，《兄弟》更夸张荒诞，《文城》更抒情）。书内年代政治话术（土改、公社、食堂宣传语）属题材强制内容，仅在写对应年代时使用，不属于余华个人语言惯性。

## 五、人写模拟技术（全局强制）

> 以下8项技术为全局强制，写作时须逐项落实。这些技术主动注入"人写"特征，与各维度的🤖规避规则互补。

| 编号 | 技术 | 具体操作 | 量化要求 |
|:---:|---|---|---|
| E1 | 思维跳跃注入 | 在叙述中途插入1-2处讲述人的闲笔联想（如对某件旧物、某个不相干人的追忆），再拉回主线 | 每篇至少1处 |
| E2 | 质量不均制造 | 故意让1-2个句子写得"粗糙"或"不够好"（口语化碎句、半截话），保持人类写作的不完美感 | 每篇至少1句口语化碎句 |
| E3 | 具体到不能再具体的细节 | 用"家里没有糖，便到村里人家那里去要了点糖，说过些日子卖了粮再还"替代"给孩子弄了点吃的" | 每篇至少2处具体细节 |
| E4 | 允许跑题 | 在主线之外有1-2句话的偏离（如讲述人对年轻时无关小事的絮叨），然后自然拉回 | 每篇至少1处跑题 |
| E5 | 信息不对称制造 | 死亡/重大变故写得极短（几乎无信息），死亡前后的日常琐事写得极细（密度极高） | 全文信息密度差异≥3倍 |
| E6 | 个人语言怪癖复现 | 复现余华惯用词："我心想""我对自己说""嘿嘿笑""嘻嘻笑""完啦""他娘的"，以及母题词重复（如"光耀祖宗"式反复出现） | 每篇至少3次复现 |
| E7 | 体验性细节优先 | 用身体反应替代心理描写（"我眼睛一黑""腿开始发软""心里跟针扎一样"），用日常动作替代环境描写 | 体验性细节占比≥60% |
| E8 | 句长极差制造 | 确保全篇最短句（5字以内，如"死了。"）与最长句（40字以上）的长度差超过35字 | 句长标准差≥15 |

## 六、种子文本库（全局强制）

> **核心机制**：写作时禁止从零生成，必须以原文段落为模板改写。人写文本本身具有真实的统计特性，以之为模板改写时，产出的文本天然继承原文的统计指纹。以下为从《活着》摘录的种子文本，每段标注出处与功能类型。

### 种子1：开篇段（框架叙事入场 + 游荡者自述）

> 我比现在年轻十岁的时候，获得了一个游手好闲的职业，去乡间收集民间歌谣。那一年的整个夏天，我如同一只乱飞的麻雀，游荡在知了和阳光充斥的村舍田野。我喜欢喝农民那种带有苦味的茶水，他们的茶桶就放在田埂的树下，我毫无顾忌地拿起漆满茶垢的茶碗舀水喝，还把自己的水壶灌满，与田里干活的男人说上几句废话，在姑娘因我而起的窃窃私笑里扬长而去。
> ——第一章

**结构特征**：第一人称回忆开场（"我比现在年轻十岁的时候"） → 职业/身份一句交代 → 长句铺陈游荡细节，逗号连缀，弱比喻（"如同一只乱飞的麻雀"）收尾。句长递增，末句最长。

### 种子2：死亡陈述段（白描死亡 + 动作化悲痛）

> 老全说完这话，过了没多久就死了。老全死后脑袋歪到了一旁，我和春生知道他已经死了，互相看了半晌，春生先哭了，春生一哭我也忍不住哭了。
> ——第四章

**结构特征**：死亡以一句平静陈述完成（"过了没多久就死了"） → 尸体姿态的素笔白描 → 旁观者反应用动作写（"互相看了半晌""先哭了"），无任何抒情议论。全是短句，逗号连缀。

### 种子3：对话冲突段（口语对话 + 动作插入 + 内心独白）

> 家珍还是说："你跟我回去。"
> 我给了她两巴掌，家珍的脑袋像是拨郎鼓那样摇晃了几下。挨了我的打，她还是跪在那里，说：
> "你不回去，我就不站起来。"
> 现在想起来叫我心疼啊，我年轻时真是个乌龟王八蛋。这么好的女人，我对她又打又踢。
> ——第一章

**结构特征**：对话独立成段、短促重复（"你跟我回去"两次出现） → 暴力动作用弱比喻带过（"像是拨郎鼓"） → 讲述人跳出来自嘲忏悔（"乌龟王八蛋"），情绪由粗话承担。

### 种子4：时代荒诞段（黑色幽默 + 民间逻辑）

> 队长是个喜欢听道理的人，不管谁说什么，他只要听着有理就相信。……买来的人说："没有更大的了，只能一锅一锅煮了。"……有庆听了这话也嘻嘻笑，他说："要不钢铁没煮成，桶底就先煮烂啦。"谁知队长听了这话，眉毛往上一吊，看着我说："福贵，这小子说得还真对。你家出了个科学家。"队长夸奖有庆，我心里当然高兴，其实有庆是出了个馊主意。
> ——第五章

**结构特征**：荒诞事件（煮钢铁）一本正经地写 → 人物对话承担全部喜剧效果 → 讲述人补一句冷面点评（"其实有庆是出了个馊主意"），不解释笑点。

### 种子5：收束段（空镜头 + 轻度诗化 + 歌谣）

> 老人和牛渐渐远去，我听到老人粗哑的令人感动的嗓音在远处传来，他的歌声在空旷的傍晚像风一样飘扬，老人唱道：
> 少年去游荡，中年想掘藏，老年做和尚。
> 炊烟在农舍的屋顶袅袅升起，在霞光四射的空中分散后消隐了。……我知道黄昏正在转瞬即逝，黑夜从天而降了。我看到广阔的土地袒露着结实的胸膛，那是召唤的姿态，就像女人召唤着她们的儿女，土地召唤着黑夜来临。
> ——第十章

**结构特征**：人物动作收场（渐渐远去） → 歌谣独立成段作锚点 → 景物空镜头（炊烟、霞光、田野） → 全书唯一允许的轻度诗化比喻收尾，无总结、无升华、无议论。
