# 写像《常识》中译本

## 边界

- 托马斯·潘恩《常识》，武建勋、申梦琪译，中信出版集团，2013。政治论说文；规则只描述中译本语言，不代表英文原文或潘恩全部著作。
- 只学词、句、标点、语域、修辞；不学政治立场、历史判断、宗教引述与论证素材。
- 不复制原句、专名、历史人物、宗教经文、独创比喻。

## 语感总述

像一位受过古典训练的律师在公开辩论：先区分概念，再把条件、让步、反例装进长句；句子长短不齐，段落也不整齐。判断常在一段中间出现，问句多在段中自问自答，很少压在段末。

总纲：长句装论证，短句落判断；段落可以不匀；不每段对偶、不段末反问、不套「不是…而是…」；以「我们」建立共同体，标点与文言虚词不超源频率。

## 硬约束

### 1. 长句随功能伸缩，段落允许不匀〔句法/篇章〕〔硬性〕

- 动作：定义、因果、让步处用 2–4 层复句，把条件、原因、反例装进一句；转折、判断处收短。段落随论证走，允许单句段。
- 频率：句均 44.2 字，31.1% ≥50 字；段均 181 字，19.6% 单句段。
- 上限：不设每段字数；不要每段都以金句收尾。
- 证据：S01、S02、S20
- 例外：清单不适用。

### 2. 第一人称论辩姿态，问句放在段中〔语域/话语〕〔硬性〕

- 动作：以「我们」承担共同体判断，以「我」下个人判断；可呼告「你们」，但不空喊「让我们」；问句用来推进，紧跟「因为/因此」自答，不放段末。
- 频率：我们 10.3/千字，我 2.7，你们 1.3；问句占 6.0%，段末问句仅 2.1%。
- 上限：问句 ≤2/千字；段末问句 ≤1 篇。
- 证据：S15、S19、S20、S24
- 例外：呼告段可用一个段末问句。

### 3. 定义/纠偏用「所谓/即/不外乎」，不套「不是…而是…」〔句法/修辞〕〔硬性〕

- 动作：区分概念先用「所谓……是指……」「……即……」「……不外乎……」；确需对比用「前者……后者……」；「不是……而是……」全文最多 1 次，且必须是真纠偏。
- 频率：「不是……而是……」4/585 句（0.68%）、4/143 段（2.8%）；「并非……而是……」5/585（0.85%）。
- 上限：全文 0–1 次；禁止作段落框架。
- 证据：S01、S08、S13

### 4. 标点按句法需要分层，不超过源频率〔标点〕〔硬性〕

- 动作：并列/对比才用分号，定义/引语/列举才用冒号，补充才用破折号；句号能断就断；引号只标概念、他人说法、反讽。
- 频率：分号 2.55/千字，冒号 2.24，破折号 1.24，引号 1.66。
- 上限：分号 ≤3，冒号 ≤3，破折号 ≤1.5，引号 ≤2；均每千字，超过就删。
- 证据：S03、S05、S11、S16
- 例外：清单按原文。

### 5. 文言虚词与四字格点到为止〔词法〕〔条件〕

- 动作：只在转折、让步、推论处用「倘若/即使/既然/无论/尽管/亦/则/故/并非/换言之」；四字格只放判断句或段末，不连续堆叠。
- 频率：倘若 10、即使 11、既然 17、尽管 8（全篇 2.6 万字）。
- 上限：每千字 ≤3 个文言虚词；四字格每段 ≤1 个。
- 证据：S04、S06、S18
- 例外：引语不适用。

## 失败模式

每段对偶加段末反问；「不是……而是……」连用；标点超密度；文言/四字格堆砌；段落等长、每段金句收尾。

## 写作流程

1. 先写不整齐的草稿：长句装论证，短句落判断，段落不等长。
2. 查低频句式与标点密度：「不是…而是…」≤1，问句 ≤2/千字，分号/冒号/引号不超上限。
3. 成稿后跑 `02-validation.md`，按源频率做指标对照。
