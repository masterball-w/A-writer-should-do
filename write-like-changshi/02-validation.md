# 校验：常识（中译本）

## AI 黑名单（12 条）

1. 「不是……而是……」作框架：源书仅 4/585 句（0.68%），全文最多 1 次，不得每段用。
2. 每段一个对偶、三连排比、对称短长句。
3. 段末反问收尾：源书仅 3/143 段（2.1%）。
4. 「首先/其次/最后」机械三段。
5. 「综上所述」。
6. 「值得注意的是」。
7. 「不可否认」。
8. 「在当今社会」。
9. 「不仅……而且……」空泛递进。
10. 「让我们……」空喊，无具体动作。
11. 抽象名词堆叠；「深刻/生动/丰富/独特」等空洞形容词。
12. 分号/冒号/引号超密度：源书 2.55/2.24/1.66 每千字，生成不得超过 3/3/2。

## 负面样本（5 条）

1. 错：这不是一次调整，而是一次重生；这不是结束，而是开始。
   改：删掉连用的「不是……而是……」，用「所谓……是指……」或「前者……后者……」把差异写具体；全文最多一次。
2. 错：每段都用一个对偶，段末都用一个反问。
   改：只在定义/纠偏段用一次对比；问句放段中，紧跟「因为/因此」自答；段末用判断。
3. 错：分号、冒号、引号密集，句子被切碎。
   改：句号能断就断；分号只用于并列/对比，冒号只用于定义/引语/列举，引号只标概念/反讽。
4. 错：倘若、即使、既然、尽管、亦、则、故连续出现，四字格一段三个。
   改：每千字文言虚词 ≤3；四字格每段 ≤1，只放判断处。
5. 错：八段等长，每段都以金句收尾。
   改：允许单句段和长短不齐；判断可以落在一段中间，不要每段都收金句。

## AI 味校验（先对源书基线）

通用清单只在源书没有、或成稿明显高于源书时启用；对偶、分号、破折号、长句、文言虚词在源频率内不算 AI 味。

| 级别 | 检查项 | 处置 |
|---|---|---|
| A | 「不是……而是……」等翻案腔；「核心是/关键在于/原因如下」结论冒号；「说白了/先说结论」 | 对举全文 ≤1；提示语删除或改句号；起手式删 |
| B | 前置定语 >15 字或两个以上「的」；「当……时」前置；「对于……来说」壳；一句 ≥3 项顿号；相邻三句同构；段段以「因此/然而」起段 | 拆句、换语序、概括并列、打散一句；不删信息 |
| C | 句长 CV、段落等长、小标题密度 | 只报告，不机械制造参差 |
| F | 分号/冒号/破折号/引号密度 | 按上限处理；低密度不补写 |
| X | 正文问句、序数词小标题、「这意味着」、列表引出冒号、概括替代 | 永不改 |
| H | 比喻、拟人喻体 | 只列不改，默认保留 |

- 报告先写「本篇命中 / 源书基线 / 处置」，再改写；每处改动说明对应项。
- 改写七原则：最小改动、信息守恒、不制造参差、结构不动、风格优先、引文不改、改后复测。

## 验收清单（15 项）

- [ ] 全文「不是……而是……」≤1，且不是段落框架。
- [ ] 问句 ≤2/千字；段末问句 ≤1；问句多在段中自答。
- [ ] 分号 ≤3、冒号 ≤3、破折号 ≤1.5、引号 ≤2（每千字）。
- [ ] 段落长度不匀，至少一个单句段或短段；不是每段等长。
- [ ] 长句有条件/让步/因果层次，不是逗号堆叠。
- [ ] 第一人称以「我们」为主，不空喊「让我们」。
- [ ] 文言虚词 ≤3/千字；四字格每段 ≤1，不堆叠。
- [ ] 引号只标概念/反讽/他人说法。
- [ ] 段末多数是判断，不是反问；没有每段金句。
- [ ] 无 AI 黑名单命中。
- [ ] 朗读顺，删标志词后仍有语感。
- [ ] 未复制原句、专名、历史人物、宗教经文、独创比喻。
- [ ] 未把政治立场、历史判断、宗教引述当成风格要求。
- [ ] 指标对照：关键密度未超源书 2 倍；负向指纹未违反。
- [ ] AI 味校验表已填：源书基线内未误改；X 级零改动；改写后已复测。
