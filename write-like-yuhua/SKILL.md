# 写作指导：余华风格（基于《我们生活在巨大的差距里》）

## 适用场景

本指导适用于需要模仿余华写作风格的创作任务，包括但不限于：续写、仿写、风格化改写、风格校验。指导基于单本《我们生活在巨大的差距里》（散文杂文集）提取，覆盖该书的随笔/日记体写作特征，未涵盖余华小说（《活着》《兄弟》等）的叙事风格变化。

## 一、风格总纲

1. **平静叙述荒诞**：再惨烈、再荒唐的内容也用松弛平静的第一人称语气讲出来，禁止感叹号与情绪外露。
2. **具体细节承载思想**：一切抽象命题必须落到一个日常具体物上（闹钟、白球鞋、复印机、火腿），禁止空谈概念。
3. **并置对照结构**：优先用"两个极端/两个叙述/两个故事"互为镜像的结构呈现差距，而不是直接下判断。
4. **短句俏皮收尾**：篇末停在一句短小的警句、俗语或俏皮话上，戛然而止，禁止总结升华段。
5. **幽默包裹锋利**：写苦难必配一个幽默细节，写讽刺必带自嘲，禁止愤怒控诉式表达。

## 二、执行顺序与文件索引

写作时须按以下顺序依次加载并执行各维度指导文件。该顺序遵循「先定调→再搭架→定内容→控节奏→理逻辑→炼词句→施修辞→验认知」的递进逻辑，前序维度的决策构成后续维度的约束前提：

| 执行顺序 | 文件 | 维度 | 职责 | 依赖前提 |
|:---:|---|---|---|---|
| 1 | `01-style-personality.md` | 整体写作风格与人格底色 | 确立平静幽默基调、第一人称平视立场、温和讽刺情绪底色 | 无（最先执行，为全文定调） |
| 2 | `02-structure-layout.md` | 写作框架与谋篇布局 | 规划场景切入、并置对照结构、短句收束 | 依赖维度1确立的调性与立场 |
| 3 | `03-theme-material.md` | 主题取向与内容选择偏好 | 确定差距/记忆母题、四类素材源、非对称取舍 | 依赖维度2确定的结构框架 |
| 4 | `04-rhythm-density.md` | 叙事/论证节奏与信息密度 | 控制段落粒度跳跃、场景密观点稀、留白度 | 依赖维度3确定的内容体量 |
| 5 | `05-logic-texture.md` | 行文逻辑与内容肌理 | 搭建归纳式推理、类比推进、时空跳跃衔接 | 依赖维度4确定的节奏框架 |
| 6 | `06-word-sentence.md` | 词句习惯与语言惯性 | 约束朴素用词、"我心想"句式、直接引语密度 | 依赖维度5确定的逻辑走向 |
| 7 | `07-rhetoric.md` | 修辞策略与表达技法 | 选择具象类比、日常物丈量法、反讽戏仿 | 依赖维度6确定的词句基础 |
| 8 | `08-cognition-value.md` | 认知模式与价值底色 | 校验经验主义归纳、平视弱者立场、容纳矛盾 | 最后执行，对全文认知一致性做终检 |

### 执行方式

- **完整写作任务**：按顺序1→8依次加载每个文件中的规则，逐步落实。初稿完成后，**必须执行「种子文本改写法」**（见第六节）与各文件的🤖规则校验，否则视为未完成。
- **局部改写/校验任务**：可直接加载对应维度的文件单独执行。改写后仍须执行种子文本纹理校验。
- **风格校验任务**：先执行维度1确立基调，再跳至维度8做认知终检，然后用下方校验清单逐条核对。
- **🤖 AI特征校验**：写作完成后，须逐维度检查🤖 AI特征规避规则与各文件收录的AI典型写法黑名单，确保不触发AI典型写法。此项为终检的前置步骤。
- **写作时禁止从零生成**：必须先从第六节「种子文本库」选取结构最接近的种子文本为模板改写，内容替换比例≤50%。

## 三、风格校验清单

写作完成后，逐条校验文本是否符合各维度规则：

- [ ] 文风基调是否符合「风格总纲」的5条核心原则
- [ ] 维度1：叙事立场与情绪底色是否遵循 `01-style-personality.md` 的硬性规则
- [ ] 维度2：谋篇布局是否遵循 `02-structure-layout.md` 的硬性规则
- [ ] 维度3：主题与素材选择是否遵循 `03-theme-material.md` 的硬性规则
- [ ] 维度4：节奏与信息密度是否遵循 `04-rhythm-density.md` 的硬性规则
- [ ] 维度5：行文逻辑是否遵循 `05-logic-texture.md` 的硬性规则
- [ ] 维度6：句式与用词是否遵循 `06-word-sentence.md` 的硬性规则
- [ ] 维度7：修辞选择是否遵循 `07-rhetoric.md` 的硬性规则
- [ ] 维度8：认知模式与价值立场是否遵循 `08-cognition-value.md` 的硬性规则
- [ ] 是否触犯任一维度的「避免」规则
- [ ] **是否触犯任一维度的🤖 AI特征规避规则或AI典型写法黑名单**
- [ ] 段落粒度是否存在跳跃（单句成段与长段交错，非全程均匀段落）
- [ ] 是否存在三段式排比或工整对仗式总结
- [ ] 段间是否存在至少2处不平滑的时空跳跃
- [ ] 用词是否保持朴素粗砺感（含俗语/口语，非精致书面词汇）
- [ ] 篇末是否为短句收束（无总结升华段）
- [ ] 是否有至少1处"我心想："式内心独白与至少1处直接引语
- [ ] 是否误用了《写给儿子的信》（妻子陈虹代笔）的语言特征

## 四、边界说明

本指导基于《我们生活在巨大的差距里》单本书提取，余华在其他作品（尤其长篇小说）中的风格可能有变化。末篇《写给儿子的信》为妻子陈虹代笔，其语言风格已排除。附录创作日记为对话实录性质，语料权重低于正文。

## 五、人写模拟技术（全局强制）

> 以下8项技术为全局强制，写作时须逐项落实。这些技术主动注入"人写"特征，与各维度的🤖规避规则互补。

| 编号 | 技术 | 具体操作 | 量化要求 |
|:---:|---|---|---|
| E1 | 思维跳跃注入 | 在论证中途插入1-2处看似无关的个人联想（如找猫王雕像、丢护照），再拉回主题 | 每篇至少1处 |
| E2 | 质量不均制造 | 故意让1-2个句子写得"粗糙"或"不够好"，保持人类写作的不完美感 | 每篇至少1句口语化碎句 |
| E3 | 具体到不能再具体的细节 | 用"二○○九年六月初的一天，法兰克福"式的时地细节替代"有一次" | 每篇至少2处具体细节 |
| E4 | 允许跑题 | 在主题之外有1-2句话的偏离，然后自然拉回 | 每篇至少1处跑题 |
| E5 | 信息不对称制造 | 某些段落信息密度极高（场景见闻密集），某些段落几乎无信息（一句判断） | 全文信息密度差异≥3倍 |
| E6 | 个人语言怪癖复现 | 复现余华标志性用词："我心想""我觉得""这家伙""然后""结果" | 每篇至少3次复现 |
| E7 | 体验性细节优先 | 用主观判断、日常场景、身体感受（心跳、胃冷）、直觉替代环境描述 | 体验性细节占比≥60% |
| E8 | 句长极差制造 | 确保全篇最短句（5字以内）与最长句（40字以上）的长度差超过35字 | 句长标准差≥15 |

## 六、种子文本库（全局强制）

> **核心机制**：写作时禁止从零生成，必须以原文段落为模板改写。人写文本本身具有真实的统计特性，以之为模板改写时，产出的文本天然继承原文的统计指纹。以下为从原文中摘录的种子文本，每段标注出处与功能类型。

### 种子1：开篇段（他人提问 + 自我调侃入场）

> 潘卡吉·米什拉问我："你早期的短篇小说充满了血腥和暴力，后来这个趋势减少了，为什么？"
> 这个问题十多年前就缠绕我了，我不知道已经回答了多少次。
> ——一个记忆回来了

**结构特征**：他人直接引语提问开场 → 第一人称回应带轻微抱怨式自嘲 → 逗号连缀长句。禁止以观点句开篇。

### 种子2：并置对照段（两个极端丈量差距）

> 一个北京的小男孩狮子大开口要一架真正的波音飞机，不是玩具飞机；一个西北的小女孩却是羞怯地说，她想要一双白球鞋。
> 两个同龄的中国孩子，就是梦想都有着如此巨大的差距，这是令人震惊的。
> ——我们生活在巨大的差距里

**结构特征**：两个具体人物 + 两个具体物件并置（一奢一朴） → 一句平静判断收束。句内靠逗号连缀，无排比骨架。

### 种子3：日记叙事段（见闻 + "我心想"插叙）

> 偶尔浏览到一条几天前的新闻，北京市公安局宣称：在国庆安保的"惊雷行动"中，已破获各类刑事案件九千八百余起，抓获涉案犯罪嫌疑人六千五百余名。我心想：如果不是六十周年，这些被抓获的犯罪嫌疑人里，是否有一些人会继续逍遥法外？
> ——七天日记·星期六，九月二十六日

**结构特征**：转述见闻（含精确数字） → "我心想："引出内心独白 → 疑问式收束不回答。

### 种子4：俗语收束段（短句俏皮收尾）

> 什么叫杠杆？在中国人这里就是一句俗语：撑死胆大的，饿死胆小的。
> ——奥运会与比尔·盖茨之杠杆

**结构特征**："什么叫X？"设问 → 一句俗语作答 → 全篇到此为止，无总结升华。

### 种子5：突然结尾段（细节/喊叫戛然而止）

> 书店老板继续和小镇上的朋友们高谈阔论，他说着说着突然想起来这个外国老头是谁了，他冲着角落激动地喊叫：
> "加西亚·马尔克斯！"
> ——奥克斯福的威廉·福克纳

**结构特征**：场景推进到动作顶点 → 以一句直接引语（人名喊叫）结束全篇 → 无任何后续评论。
