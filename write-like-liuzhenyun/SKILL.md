# 写作指导：刘震云风格（基于《一日三秋》）

## 适用场景

本指导适用于需要模仿刘震云写作风格的创作任务，包括但不限于：续写、仿写、风格化改写、风格校验。指导基于单本《一日三秋》提取，覆盖该书的小说叙事特征（元叙事前言、传说体、链条对话、逗号连缀长句），未涵盖刘震云其他作品（《一句顶一万句》《我不是潘金莲》等）的风格变化。

## 一、风格总纲

1. **以笑话写哭**：再惨烈的内容也用讲笑话的平静语气讲，死亡与荒诞必须配一个笑点，禁止煽情与控诉；篇末可用一句"这是本笑书，也是本哭书"式的定性收束。
2. **日常物丈量生死**：一切重大命题必须落到一件芝麻大的具体物上（一把韭菜、一碗胡辣汤、一根鱼刺、两毛钱汽水），禁止抽象论述。
3. **链条对话推进**：对话以"X说……又说……又说……"链条与"姓名：'话'"剧本式提示推进，对话段占比向40%看齐；叙述段则用逗号、分号连缀成绵延超长句，句号密度压到最低。
4. **绕圈归因，判断即消解**：因果链故意绕三四层才说破（"一件事引出另一件事"）；严肃判断出口紧接自我否定（"这就是你的命……命不命的，也是胡说"），禁止显性因果链与稳定观点输出。
5. **说书人姿态，不开药方**：以民间说书人口吻（"花开两朵，各表一枝""不在话下"）全知叙述，只呈现不评判、不给解决方案；鬼神与日常生活平权并置，荒诞只陈述不解释。

## 二、执行顺序与文件索引

写作时须按以下顺序依次加载并执行各维度指导文件。该顺序遵循「先定调→再搭架→定内容→控节奏→理逻辑→炼词句→施修辞→验认知」的递进逻辑，前序维度的决策构成后续维度的约束前提：

| 执行顺序 | 文件 | 维度 | 职责 | 依赖前提 |
|:---:|---|---|---|---|
| 1 | `01-style-personality.md` | 整体写作风格与人格底色 | 确立冷面黑色幽默基调、说书人平视立场、笑中含泪情绪底色 | 无（最先执行，为全文定调） |
| 2 | `02-structure-layout.md` | 写作框架与谋篇布局 | 规划套层框架、非对称详略、时间折叠与短句收束 | 依赖维度1确立的调性与立场 |
| 3 | `03-theme-material.md` | 主题取向与内容选择偏好 | 确定笑话/离开母题、小人物与鬼神素材、非对称取舍 | 依赖维度2确定的结构框架 |
| 4 | `04-rhythm-density.md` | 叙事/论证节奏与信息密度 | 控制超长句与碎短句跳跃、对话密度、时间压缩 | 依赖维度3确定的内容体量 |
| 5 | `05-logic-texture.md` | 行文逻辑与内容肌理 | 搭建绕圈归因、藤蔓挂接、悖论断言与判断消解 | 依赖维度4确定的节奏框架 |
| 6 | `06-word-sentence.md` | 词句习惯与语言惯性 | 约束"又说"链条、方言土语、标点连缀习惯 | 依赖维度5确定的逻辑走向 |
| 7 | `07-rhetoric.md` | 修辞策略与表达技法 | 选择日常物丈量法、谐音双关、降格归谬 | 依赖维度6确定的词句基础 |
| 8 | `08-cognition-value.md` | 认知模式与价值底色 | 校验负负为正的真假辩证、平视立场、不开药方 | 最后执行，对全文认知一致性做终检 |

### 执行方式

- **产出落盘**：写作产出须按母 Skill「步骤8：写作产出落盘」执行，成稿以 `{文章标题}.md` 保存到当前工作目录，禁止仅在对话中输出不落盘。
- **完整写作任务**：按顺序1→8依次加载每个文件中的规则，逐步落实。初稿完成后，**必须执行「种子文本语感校准」**（见第六节）与各文件的🤖规则校验，否则视为未完成。
- **叙事逻辑自检**：初稿完成后，须额外执行一遍独立于风格校验的叙事逻辑自检：①人物称谓与排行辈分是否一致（哥/弟/叔/婶不得错乱，以设定的人物关系网为准）；②对话内部是否自相矛盾（如前句问价、后句质疑收钱）；③机构名称、证件有效期、办事程序等设定是否前后一致（改名、合并须全文同步）；④时间、年龄、金额是否自洽。风格校验只保文风，不保逻辑，两项缺一不可。
- **局部改写/校验任务**：可直接加载对应维度的文件单独执行。改写后仍须执行种子文本语感校准。
- **风格校验任务**：先执行维度1确立基调，再跳至维度8做认知终检，然后用下方校验清单逐条核对。
- **🤖 AI特征校验**：写作完成后，须逐维度检查🤖 AI特征规避规则与各文件收录的AI典型写法黑名单，确保不触发AI典型写法。此项为终检的前置步骤。
- **内容按规则全新生成**：第六节「种子文本库」仅作结构参照与语感校准——为目标段落选取结构最接近的种子文本，对齐其段落功能、句长节奏、过渡与收束方式；禁止改写原文句子、禁止套用原文句式骨架、禁止原文人物与场景进入新作。

## 三、风格校验清单

写作完成后，逐条校验文本是否符合各维度规则：

- [ ] 文风基调是否符合「风格总纲」的5条核心原则
- [ ] 维度1：冷面幽默与说书人立场是否遵循 `01-style-personality.md` 的硬性规则
- [ ] 维度2：套层结构与详略倒置是否遵循 `02-structure-layout.md` 的硬性规则
- [ ] 维度3：主题与素材选择是否遵循 `03-theme-material.md` 的硬性规则
- [ ] 维度4：超长句与碎短句的节奏跳跃是否遵循 `04-rhythm-density.md` 的硬性规则
- [ ] 维度5：绕圈归因与判断消解是否遵循 `05-logic-texture.md` 的硬性规则
- [ ] 维度6："又说"链条与方言用词是否遵循 `06-word-sentence.md` 的硬性规则
- [ ] 维度7：日常物丈量与比喻克制是否遵循 `07-rhetoric.md` 的硬性规则
- [ ] 维度8：真假辩证与不开药方是否遵循 `08-cognition-value.md` 的硬性规则
- [ ] 是否触犯任一维度的「避免」规则
- [ ] **是否触犯任一维度的🤖 AI特征规避规则或AI典型写法黑名单**
- [ ] 是否存在至少1处惨烈内容与笑点无过渡并置
- [ ] 是否存在至少1处逗号连缀超长句（≥80字）与至少1处5字以内碎短句
- [ ] 对话段占比是否向30%以上看齐，且含"又说/又问"链条
- [ ] 是否存在至少1处大事一笔带过、小事工笔细描的详略倒置
- [ ] 篇末是否为短句定性收束（无总结升华段、无解决方案）
- [ ] 叙事逻辑自检是否通过：称谓辈分、对话因果、设定一致性、时间数字均无矛盾
- [ ] 是否误把戏曲唱词体当作常规句式滥用（唱词体全书仅2处，属局部技法）

## 四、边界说明

本指导基于《一日三秋》单本书提取，刘震云在其他作品（《一句顶一万句》《我不是潘金莲》《一地鸡毛》等）中的风格可能有变化。书中戏曲唱词为题材强制内容，民谣体四句诗为该章文体设计，均不作为通用句式规则。

## 五、人写模拟技术（全局强制）

> 以下8项技术为全局强制，写作时须逐项落实。这些技术主动注入"人写"特征，与各维度的🤖规避规则互补。

| 编号 | 技术 | 具体操作 | 量化要求 |
|:---:|---|---|---|
| E1 | 思维跳跃注入 | 在叙事中途插入1-2处看似无关的岔事（如蚊子报丧、死鱼生气），再拉回主线 | 每篇至少1处 |
| E2 | 质量不均制造 | 故意让1-2句写得"粗糙"（如"跟床单精湿没关系"式的大白话），保持人写的不完美感 | 每篇至少1句粗糙口语 |
| E3 | 具体到不能再具体的细节 | 用"两毛钱汽水""三年五个月零二十三天"式精确细节替代模糊表述 | 每篇至少2处精确细节 |
| E4 | 允许跑题 | 有1-2句偏离主线的话（如介绍痰盂的来历），然后自然拉回 | 每篇至少1处跑题 |
| E5 | 信息不对称制造 | 某些段落密度极高（一段塞进数年前因后果），某些段落只有一句对话 | 全文信息密度差异≥3倍 |
| E6 | 个人语言怪癖复现 | 复现刘震云标志性用词："又说""后来""或者，""咋办""啥意思""不在话下" | 每篇至少5次复现 |
| E7 | 体验性细节优先 | 用身体反应（起了一层冷汗、触电一样）、具体动作替代心理描写与环境描述 | 体验性细节占比≥60% |
| E8 | 句长极差制造 | 确保全篇有1句≥80字的逗号连缀长句与至少2句5字以内短句 | 句长标准差≥15 |

## 六、种子文本库（全局强制）

> **用法**：种子文本是原文的结构范式与语感基准，仅作段落功能、句长节奏、过渡与收束方式的参照；写作内容一律按规则全新生成，禁止改写原文。以下为从原文中摘录的种子文本，每段标注出处与功能类型。

### 种子1：开篇段（问答链条入场 + 短句白描收束）

> 花二娘是个爱听笑话的人。人问，花二娘，从哪儿来？花二娘说，望郎山。人问，干吗去？花二娘说，找笑话。人问，眉毛上咋还挂着霜？花二娘说，望郎山上有积雪。花二娘胳膊上一篮子，篮子里装满灯笼一样的红柿子。
> ——第2章 花二娘

**结构特征**：一句定性短句开场 → 三组"人问……说……"问答链条（问句越来越怪） → 以一个具体物件（篮子/红柿子）的白描收束。禁止以观点句或背景铺垫开篇。

### 种子2：叙述段（逗号分号连缀超长句 + 时间压缩）

> 武汉机务段的职工有五千多人，陈长杰刚来时，除了舅舅，谁都不认识；对同事，慢慢才熟悉起来；刚当司炉，如何往炉膛里填煤，火车启动时填多少，跑起来填多少，多快的速度填多少，平原上填多少，山路填多少，填煤又如何省煤，都有诀窍，一切都要从头学起；父子俩睡单身宿舍，等于在武汉上无片瓦，下无立锥之地；陈长杰来武汉之后，没想过再成家这件事。陈长杰早年爱说话，现在不爱说话了；早年爱说笑话，现在不爱说笑话了。不知不觉，三年就过去了。
> ——第一章 当年

**结构特征**：精确数字开场 → 分号连缀挂接多层信息（一个句号之前塞进数年的生活） → 以"早年……现在……"的对举短句收拢 → 最后一句"不知不觉，三年就过去了"单句压缩时间。

### 种子3：对话链条段（又说/又问 + 判断即消解）

> 便报了他的生辰八字。老董掐指在那里算。算了半天，叹了口气：
> "啥也不说了，这就是你的命。"
> 接着又说，"命不命的，也是胡说，不必认真，不必认真。"
> ——第二章 二十年后

**结构特征**：动作白描（掐指算、叹气） → 引号对话给出严肃判断 → "接着又说"紧跟自我否定，同一句话重复两遍（"不必认真，不必认真"）。严肃与消解必须同段完成。

### 种子4：白描悲怆段（惨烈用玩笑语气 + 具体物锚点）

> 几十年后，明亮看到手机新闻里，动不动有人上吊了，动不动有人跳楼了，身边总有人说："至于吗？""有什么过不去的事？""因为什么呀？"明亮会说："至于，因为'没劲'。"人问："你咋知道？"明亮嘴上不说，会在心里说："因为我妈。"
> ——第一章 当年

**结构特征**：时间状语起笔 → 罗列旁人轻飘飘的问话（三个连续问句） → 主人公用一个土词（"没劲"）作答 → 末句以最短的心里话（三个字）收束全段，不加任何解释与抒情。

### 种子5：收束段（短句定性 + 悖论判断）

> 三千多年来，许多延津人知道这事，但没有一个人敢对花二娘讲。特别是，不敢在梦里当笑话讲。
> 这才是延津最大的笑话。
> ——第14章

**结构特征**：长句铺陈悬案 → "特别是"补一句更拧巴的限制 → 独立成段的短句悖论判断收束全篇，戛然而止，无总结升华、无解决方案。
